# KisuKisu website

This repo holds the public website for **KisuKisu**, served at **https://kisukisu-app.github.io**.

KisuKisu is voice typing for Android. You talk the way you normally do, with the ums, restarts and "I mean"s, and it types the clean sentence you meant. A small floating bubble works in any app: WhatsApp, Gmail, Notes, anything with a text box. Speech recognition and cleanup run on the phone, so it works in airplane mode, with no account and no sign-up.

## About this repo

The pages are static HTML with no build step. They're published here from the app's main (private) repository, so changes made directly in this repo get overwritten on the next publish. The app's source code isn't in this repo.
